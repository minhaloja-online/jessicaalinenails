Como o saldo é calculado

Quando a cliente paga direto para a profissional, ela fica devendo a cota do studio. Quando paga para o studio (maquininha ou Pix do studio), o studio fica devendo a parte dela. Cada acerto registrado abate o saldo. Saldo zerado = tudo acertado.
